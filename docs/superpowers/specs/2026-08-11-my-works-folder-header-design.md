# 我的作品文件夹标题区设计

> 本说明替代 `2026-08-11-my-works-folder-filter-layout-design.md` 中“右侧固定新建按钮”的布局方案。

## 目标

参考用户提供的页面，将文件夹管理从单行筛选控件重构为清晰的两层结构：稳定可见的新建入口与专注筛选的文件夹标签分离。

## 结构

文件夹区域位于“作品 / 喜欢”标签下方：

1. `.my-works-folder-header`：左侧标题“文件夹”与作品总数圆形徽标；右侧为带 `FolderPlus` 图标的“新建”描边按钮。
2. `.my-works-folder-scroll`：只容纳“全部”“未分类”和自定义文件夹标签，可水平滚动。
3. 每个标签为独立圆角胶囊，标签名与计数徽标并列；选中态使用浅蓝色背景、蓝色文字及蓝色计数背景。
4. 作品内容区保持在文件夹区域下方，空状态沿用现有内容卡片。

## 删除交互

标签不再显示常驻删除 `×`。自定义文件夹标签通过长按（触摸端）或右键（桌面端）打开上下文菜单，提供“删除文件夹”。“全部”和“未分类”不提供删除操作。

## 保持不变

- `onFolderChange`、`onCreateFolder`、`onDeleteFolder` 的业务回调和文件夹数据模型。
- 当前页面的浅色背景、蓝色主色、圆角与间距语言。
- 作品网格及空状态内容。

## 验证

- 文件夹标题、新建按钮与横向筛选轨道是三个独立节点。
- 多文件夹时新建按钮始终可见，标签轨道单独滚动。
- 自定义文件夹不渲染常驻删除按钮，但可通过长按/右键打开删除菜单。
- 筛选、新建与删除回调保持可用。
- 相关单元测试、类型检查、H5 构建与 `git diff --check` 通过。
