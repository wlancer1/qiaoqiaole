# 项目文件夹底部弹窗设计

## 目标

将“新建文件夹”和“移动到文件夹”统一改为符合 H5 设计规范的底部弹窗，同时保持我的作品页、保存作品弹窗和作品操作菜单之间的状态连续。

## 交互结构

### 新建文件夹

- 我的作品页和保存作品弹窗共用同一个新建文件夹 Sheet。
- Sheet 使用现有遮罩、顶部圆角、拖拽指示条、底部安全区、阴影和进入动画。
- 内容包含标题、说明、文件夹名称输入框、错误区域，以及“取消 / 创建文件夹”按钮。
- 输入限制为 1–30 个字符；空名称时禁止提交。
- 打开后自动聚焦输入框。
- 点击遮罩、按 Escape 或点击取消可关闭；创建请求进行中时禁止关闭和重复提交。
- 创建失败时保留输入内容并显示接口错误。
- 创建成功后关闭 Sheet，并自动选中新文件夹。
- 从我的作品页创建成功后，将新文件夹加入列表、切换当前筛选到其 ID，并展示该文件夹的空状态。
- 从保存作品弹窗进入时，底层保存弹窗保持挂载但设为不可交互：成功时恢复保存弹窗并选中新文件夹；取消时恢复保存弹窗并保留原选择；失败时新建 Sheet 保持打开，保存弹窗继续挂载且不可交互。
- 从移动 Sheet 进入时，创建成功后返回移动 Sheet，并将新文件夹设为待移动目标。

### 移动到文件夹

- 作品操作菜单中的“移动到文件夹”不再使用原生 `select`。
- 点击后关闭作品操作菜单，打开独立的移动 Sheet。
- Sheet 展示“未分类”和所有用户文件夹，当前所在文件夹带选中状态。
- 选择目标后需点击“移动”确认，降低误操作风险。
- 未选择目标或目标与当前文件夹相同时，“移动”按钮禁用。
- 提供“新建文件夹”入口；创建成功后返回并自动选中新文件夹。
- 即使没有用户文件夹，也始终展示“未分类”和“新建文件夹”。
- 文件夹较多时，仅选项区域滚动；标题和底部操作区固定在 Sheet 内，确认按钮不被小屏或安全区遮挡。
- 移动期间锁定关闭和重复提交；失败时保留当前选择并显示错误。
- 移动成功后关闭 Sheet，刷新对应作品的 `folderId` 和更新时间。

## 组件边界

- 新增共享的文件夹 Sheet 外壳，负责遮罩、面板、指示条、标题、关闭规则、键盘安全区和焦点语义。
- `CreateProjectFolderSheet` 只负责名称输入和创建状态。
- `MoveProjectFolderSheet` 只负责目标选择、创建入口和移动确认。
- 两个 Sheet 都由 H5App 的稳定应用级覆盖层渲染，与页面内容同级，不挂靠在可能随页面分支卸载的局部 `actionSheet` 内。
- H5App 继续负责接口请求、文件夹数据、作品数据、Sheet 层级及入口之间的状态协调。
- 现有 `ProjectActionSheet` 只发出“请求移动”事件，不直接承载文件夹选择控件。

## 状态与数据流

1. 入口记录来源：我的作品、保存作品或移动作品。
2. 打开创建 Sheet 时清空旧名称和错误。
3. 创建成功后将文件夹加入列表，并根据来源更新保存目标、当前筛选或移动目标。
4. 打开移动 Sheet 时记录目标作品和其当前文件夹。
5. 用户确认后调用现有项目移动接口；成功后更新本地作品并关闭 Sheet。
6. 创建 Sheet 从移动流程关闭时恢复移动 Sheet；普通取消则返回发起它的上一层。

## 弹窗层级与页面隔离

- 任一文件夹 Sheet 打开时，锁定页面背景滚动，并将其纳入现有阻塞型弹窗状态，阻止背景点击、触摸和页面返回导航穿透。
- 新建 Sheet 叠加在保存弹窗或移动 Sheet 上时，只有最上层使用 `aria-modal="true"`；底层弹窗设置 `inert` 或等效的不可聚焦、不可点击状态，并从可访问性树中隐藏。
- 顶层遮罩点击只关闭顶层 Sheet，不向底层遮罩或页面冒泡。
- 点击 Sheet 内容不关闭；取消、遮罩和 Escape 遵循同一关闭规则。
- 请求进行中时，取消、遮罩、Escape 和重复确认均无效。
- 关闭顶层 Sheet 后恢复底层弹窗及其触发控件焦点；关闭最后一个 Sheet 后恢复页面触发按钮焦点和原滚动能力。

## 视觉规范

- 复用 `--sheet-backdrop`、`--sheet-width`、`--sheet-radius`、`--sheet-shadow`、`--sheet-handle` 和 `--panel`。
- 面板底部使用 `env(safe-area-inset-bottom)`。
- 主按钮使用现有蓝色主操作样式；取消按钮使用中性次操作样式。
- 文件夹选择项复用现有 Sheet 同级控件的 rem 高度和间距 Token，并提供选中、键盘焦点和禁用状态，不引入独立的全局最小触控尺寸。
- 不使用原生下拉菜单，不新增独立色板或尺寸体系。

## 可访问性

- 当前最上层 Sheet 使用 `role="dialog"`、`aria-modal="true"` 和可关联标题；被覆盖的底层弹窗按层级隔离规则移除模态语义并设为不可交互。
- 新建 Sheet 打开后聚焦名称输入框；移动 Sheet 聚焦当前选中项或第一个选项。
- Escape 遵循请求锁定规则。
- 选择项使用单选语义，确认按钮明确描述移动动作。
- Sheet 关闭后恢复到触发按钮。

## 测试

- 新建 Sheet 的底部弹窗结构、输入限制、空值禁用、创建中锁定和错误状态。
- 移动 Sheet 的当前项选中、同目标禁用、选择后确认和未分类目标。
- 从移动流程进入新建流程，创建成功后恢复移动 Sheet并自动选中。
- 保存作品弹窗在创建 Sheet 打开期间保持挂载。
- 从我的作品创建成功后，新文件夹加入列表、当前筛选切换至新文件夹 ID，并展示对应空状态。
- 从保存弹窗创建成功后，新文件夹成为保存目标；取消时保留原文件夹选择。
- 从保存弹窗创建失败后，新建 Sheet、输入内容和错误均保留，底层保存弹窗保持挂载且不可交互。
- 作品操作菜单不再渲染原生文件夹 `select`，而是触发移动 Sheet。
- 两个 Sheet 分别能从对应入口打开，取消、遮罩和 Escape 能关闭，内容点击不关闭且不触发背景页面。
- 请求期间遮罩、取消、Escape 和重复确认均无效，接口只提交一次。
- Sheet 关闭后恢复触发点焦点和页面滚动；叠加时底层保存弹窗或移动 Sheet 不可操作。
- 移动请求失败时 Sheet 保持打开并保留选择，不误关作品操作流程。
- 无用户文件夹时仍显示未分类和新建入口；长列表只滚动选项区域，标题与操作区保持可见。
- H5 类型检查、相关 Vitest、完整测试和生产构建。
