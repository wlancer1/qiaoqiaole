# 分割裁剪页 Canvas 重做设计

## 目标

将独立裁剪页改为 Canvas 渲染，确保分割后的完整格子内容稳定可见，并按参考图重做裁剪框与控制区。

## 页面结构

- 顶部继续使用现有流程导航，标题为“裁剪”，右侧为“确认裁剪”。
- 中间为深色棋盘工作区，居中显示完整分割格子图。
- 分割格子使用 Canvas 绘制，不再为每个格子创建 DOM 节点。
- Canvas 上方使用 DOM 覆盖裁剪框、框外遮罩和控制点。
- 裁剪框包含四角与四边共 8 个控制点，拖动时吸附到格线。
- 当前范围显示在裁剪框右下角，格式为“49列 × 64行”。
- 底部显示“仅保留格子内容”的说明、重置按钮和缩放控制，不显示比例选项。

## 数据与交互

- Canvas 输入仍为 `splitPreviewCells`、`activeSplitCols` 和 `activeSplitRows`。
- 裁剪框使用整数格子边界，不保存像素坐标。
- 缩放只改变裁剪工作区显示比例，不改变格子或裁剪结果。
- 确认裁剪后调用现有 `cropCells`，重新编号格子并进入浏览页。
- 全透明或无法识别有效内容时，裁剪框回退到完整网格。

## 测试

- 服务端渲染测试确认裁剪页包含 Canvas。
- 测试确认存在 8 个裁剪控制点。
- 测试确认右下角显示“列数 × 行数”。
- 保留现有自动边界和矩阵裁剪单元测试。
- 运行全量测试和 H5 生产构建。
