# 拼豆画布自适应标尺与点按取色设计

**日期：** 2026-08-21  
**范围：** H5「开始拼豆」会话画布

## 目标

当画布经缩放后超出工作区，贴边的行列标尺按可见格子的实际屏幕尺寸提高刻度密度，同时保证数字不重叠。用户在平移模式下轻点任意非透明色格时，页面选中该格的色号并高亮所有同色格。

## 标尺

`CanvasViewportRulers` 保持为缩放且画布溢出工作区时才显示；完整可见或未放大时继续使用画板自带的原有标尺。其几何计算继续使用画板 DOM 矩形与工作区 DOM 矩形：每个标签位于对应格子的真实屏幕中心，绝不根据可视区域平均分配近似位置。

新增纯函数根据已缩放的单格像素尺寸得到刻度间隔。以标签最小可读间距为约 20 CSS px：单格至少达到该间距时逐格显示；不足时选择最小的整数间隔使相邻标签达到该间距。该值与既有常规标尺的 5 格间隔取较小值，因此放大只能提高密度，不会低于原有 5 格一标；若实际尺寸仍不足以容纳更密标签，维持 5 格以避免重叠。

视口标尺只生成当前可视范围内、符合该间隔的行列数字；平移、缩放、窗口或画板尺寸变化后重新测量。标签仍以每格真实中心定位，且行列独立根据各自实际格宽/格高选择间隔。

## 画布点按取色

扩展 `useBeadingPointer` 的可选“平移模式轻点格子”回调。只有同时满足以下条件才派发取色：

- 当前交互模式为 `pan`；
- 未锁定；
- 手势是单指/单鼠标轻点，而非拖动、双指手势或取消；
- 命中有效格子。

`BeadingSessionPage` 在该回调中读取格子：透明格不处理；非透明格通过既有 `getCode` 得到色号，调用既有 `selectColor`。该函数会更新当前色并保证高亮已开启，因此画布覆盖层和右侧色号栏同步更新。标记与修改模式继续只执行原先的标记逻辑，不能意外切换颜色；锁定、拖动与双指缩放也不取色。

## 错误与兼容性

没有有效命中、透明格、锁定状态与非平移模式均为无操作。现有取色栏、键盘访问名称、缩放/平移、标记、修改、保存草稿及高亮开关的接口和行为保持不变。

## 测试

- 单元测试标尺间隔：放大后的足够大单格逐格显示；中等尺寸使用恰当整数间隔；不会降低到少于原有 5 格一标；行列按独立尺寸计算。
- 视口几何测试：仅输出可见且符合自适应间隔的数字，位置是对应格的真实屏幕中心。
- 指针测试：平移模式的有效轻点回调格索引；透明格由页面忽略；标记/修改、锁定、拖动与多指动作均不派发取色。
- 页面测试：点画布色格后选中对应色号、开启高亮；已有标记/修改流程不回归。
