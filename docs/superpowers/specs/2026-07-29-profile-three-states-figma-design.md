# “我的”页面三态 Figma 设计

## 背景

Figma 文件“超级拼 · 移动端 H5 UI（高保真）”的 `Screens` 页已有一张 `FINAL / 05 Profile` 画板，展示已登录且有仓库数据的状态。需要在不改变现有蓝色品牌视觉、页面尺寸和主要骨架的前提下，补齐“我的”页面的三种核心账号状态，便于产品评审和开发交付。

## 目标

- 在现有 Profile 画板附近并排展示三张完整页面。
- 覆盖未登录、已登录但暂无数据、已登录且有数据三种状态。
- 三张页面使用相同的 414 × 876 画板、卡片位置、底部导航和视觉语言。
- 状态差异只体现在账号卡、统计、仓库卡、历史记录提示和登录/退出操作。

## 不在范围内

- 登录中、登录失败、数据加载中、数据加载失败等瞬时或异常状态。
- 登录弹窗、注册流程、仓库创建流程等后续页面。
- Profile 之外的首页、分割、浏览和豆子清单画板。
- 对现有代码实现的修改。

## Figma 组织

采用三张独立画板方案，便于同时查看、标注和交付。画板在 `Screens` 页横向并排放置，使用一致间距，并按状态命名：

1. `FINAL / 05A Profile / Logged Out`
2. `FINAL / 05B Profile / Empty`
3. `FINAL / 05C Profile / Populated`

现有 `FINAL / 05 Profile` 作为有数据状态的基础稿；通过克隆形成另外两张状态稿，再整理原画板命名。不得删除或覆盖其他页面。

## 三态内容

### 未登录

- 账号卡使用默认头像，不显示真实昵称、用户 ID 或认证徽章。
- 主文案为“登录后管理你的拼豆世界”，提供明显的“登录 / 注册”按钮。
- 项目、仓库、库存三项统计均显示 `—`，避免伪造数据。
- 仓库卡保留原位置和尺寸，改成登录受限提示：“登录后查看豆子仓库”。
- 历史记录保留入口，但副文案提示需要登录。
- 帮助中心和设置保持可用。
- 隐藏退出登录按钮，并利用留白保持页面稳定。

### 已登录但暂无数据

- 账号卡显示示例昵称与用户 ID，但不展示虚假的会员或认证权益。
- 三项统计为“0 个项目 / 0 个仓库 / 0 色在库”。
- 仓库卡改为空状态：“还没有豆子仓库”，提供“创建仓库”行动提示。
- 历史记录副文案为“还没有编辑与导出记录”。
- 帮助中心、设置和退出登录保持可用。

### 已登录且有数据

- 保留现有账号、统计、仓库色号、库存进度、菜单和退出登录内容。
- 仅整理画板与状态相关图层命名，不改变当前高保真视觉。

## 视觉与交互原则

- 沿用现有深蓝渐变 Hero、蓝色强调色、白色圆角卡片、浅灰蓝背景和阴影层级。
- 保持 44 px 以上的主要触控目标，正文和辅助文案维持现有字号层级。
- 空状态和受限状态通过图标、短文案与按钮表达，不降低整卡透明度，确保可读性。
- 三态的共用模块应尽量保持相同坐标和尺寸，减少状态切换时的布局跳动。
- 本次仅交付静态状态画板，不新增原型连线。

## 验收

- `Screens` 页可同时看到三张 Profile 状态画板，命名清楚且顺序正确。
- 三张画板均为 414 × 876，底部导航中“我的”为激活态。
- 未登录稿无真实用户数据与退出登录按钮。
- 空数据稿所有统计为 0，仓库和历史记录都有明确空状态。
- 有数据稿保持当前视觉与内容完整。
- 三张截图没有裁切、重叠、文本溢出、错位或缺失图标。
