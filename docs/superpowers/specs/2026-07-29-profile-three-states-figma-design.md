# “我的”页面三态 Figma 设计

## 背景

Figma 文件“超级拼 · 移动端 H5 UI（高保真）”的 `Screens` 页已有一张 `FINAL / 05 Profile` 画板，展示已登录且有仓库数据的状态。需要在不改变现有蓝色品牌视觉、页面尺寸和主要骨架的前提下，补齐“我的”页面的三种核心账号状态，便于产品评审和开发交付。

## 目标

- 在现有 Profile 画板附近并排展示三张完整页面。
- 覆盖未登录、已登录但暂无数据、已登录且有数据三种状态。
- 三张页面使用相同的 414 × 876 画板、卡片位置、底部导航和视觉语言。
- 状态差异只体现在账号卡、统计、仓库卡、历史记录提示和登录/退出操作。

## 不在范围内

- 登录中、登录失败、数据加载中、数据加载失败等瞬时或异常状态。
- 登录弹窗、注册流程、仓库创建流程等后续页面。
- Profile 之外的首页、分割、浏览和豆子清单画板。
- 对现有代码实现的修改。

## Figma 组织

采用三张独立画板方案，便于同时查看、标注和交付。画板在 `Screens` 页横向并排放置，使用一致间距，并按状态命名：

1. `FINAL / 05A Profile / Logged Out`
2. `FINAL / 05B Profile / Empty`
3. `FINAL / 05C Profile / Populated`

目标文件为用户提供的 Figma 设计文件：

`https://www.figma.com/design/DmlA1d2qH1z04AnvGKhfvm/?node-id=14-627`

链接节点 `14:627` 是首页内部蒙版，不是本次修改对象。Figwright 当前连接到同一文件的 `Screens` 页；本次以现有 Profile 根画板 `15:1102`（`FINAL / 05 Profile`）为唯一基础稿。

实施时将基础稿克隆两次：

- 原画板移动到 `(3784, 1069)` 并重命名为 `FINAL / 05C Profile / Populated`。
- 未登录克隆稿放在 `(2860, 1069)`，命名为 `FINAL / 05A Profile / Logged Out`。
- 空数据克隆稿放在 `(3322, 1069)`，命名为 `FINAL / 05B Profile / Empty`。

三张画板宽度均为 414 px，横向间距固定为 48 px。最终只保留这三张 Profile 状态画板，不额外保留第四张旧名称画板，也不得删除或覆盖其他页面。

## 三态内容

### 未登录

- 账号卡保留蓝色圆形默认头像，头像字改为“访”；隐藏认证徽章与勾选符号。
- 昵称位置显示“欢迎来到超级拼”，用户 ID 位置显示“登录后管理你的拼豆世界”。
- 在账号卡右上区域新增 104 × 42 px 的蓝色实心按钮“登录 / 注册”，作为静态主操作样式。
- 项目、仓库、库存三项统计均显示 `—`，避免伪造数据。
- 仓库卡保留原位置和尺寸，标题为“登录后查看豆子仓库”，副文案为“登录后同步库存与色号”；隐藏色号圆点、进度条和库存统计。
- 历史记录保留入口，副文案固定为“登录后查看编辑与导出记录”。
- 帮助中心和设置保持可用。
- 隐藏退出登录按钮，并利用留白保持页面稳定。

### 已登录但暂无数据

- 账号卡昵称固定为“拼豆新手”，用户 ID 固定为 `ID 20260729`；保留已登录认证徽章，不增加会员权益。
- 三项统计为“0 个项目 / 0 个仓库 / 0 色在库”。
- 仓库卡标题为“还没有豆子仓库”，副文案为“创建仓库，开始管理豆子库存”；隐藏色号圆点、进度条和库存统计，并在卡片内容区新增 104 × 40 px 的蓝色描边按钮“创建仓库”。
- 历史记录副文案为“还没有编辑与导出记录”。
- 帮助中心、设置和退出登录保持可用。

### 已登录且有数据

- 保留现有账号、统计、仓库色号、库存进度、菜单和退出登录内容。
- 仅整理画板与状态相关图层命名，不改变当前高保真视觉。

## 视觉与交互原则

- 沿用现有深蓝渐变 Hero、蓝色强调色、白色圆角卡片、浅灰蓝背景和阴影层级。
- 保持 44 px 以上的主要触控目标，正文和辅助文案维持现有字号层级。
- 空状态和受限状态通过图标、短文案与按钮表达，不降低整卡透明度，确保可读性。
- 三态的共用模块应尽量保持相同坐标和尺寸，减少状态切换时的布局跳动。
- 本次仅交付静态状态画板，不新增原型连线。

## 验收

- `Screens` 页可同时看到三张 Profile 状态画板，命名清楚且顺序正确。
- 三张画板均为 414 × 876，底部导航中“我的”为激活态。
- 三张画板依次位于 x = 2860、3322、3784，y = 1069，相邻间距均为 48 px。
- 未登录稿无真实用户数据与退出登录按钮。
- 空数据稿所有统计为 0，仓库和历史记录都有明确空状态。
- 有数据稿保持当前视觉与内容完整。
- 新增或修改的状态图层使用 `Logged Out / ...` 或 `Empty / ...` 前缀，便于开发定位。
- 三张截图没有裁切、重叠、文本溢出、错位或缺失图标。
