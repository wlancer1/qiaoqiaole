# 我的作品文件夹筛选栏布局设计

## 问题

“新建文件夹”与文件夹筛选项处于同一个横向滚动容器。自定义文件夹增加后，新建按钮会被推到轨道末端，在默认视口中不可见。

## 设计

将筛选栏拆成两个视觉区域，但保持在同一行：

- `.my-works-folder-filter` 作为固定宽度的外层布局容器。
- 新增 `.my-works-folder-scroll`，仅承载“全部作品”“未分类”和自定义文件夹，并负责横向滚动。
- `.my-works-create-folder` 位于滚动轨道之外，固定在外层容器右侧，始终可见。
- 外层通过伪元素或按钮自身背景形成轻微的左侧渐变遮罩，避免滚动内容从固定按钮下方透出。
- 窄屏下隐藏“文件夹”三个字，只显示图标和“新建”，保留不小于 44px 的触控高度。

现有蓝色、圆角、计数徽标和文件夹删除按钮样式保持不变。

## 交互与数据

文件夹筛选、删除和新建回调保持现有接口，不改数据流。结构变化只影响布局：左侧轨道可以滚动，右侧新建按钮不随轨道移动。

## 可访问性

外层继续使用 `aria-label="作品文件夹"`。滚动轨道作为纯布局容器，不增加多余 landmark；新建按钮继续保留完整可读文案。

## 验证

- 组件结构测试确认新建按钮不在 `.my-works-folder-scroll` 内。
- CSS 测试确认外层不滚动、轨道可横向滚动且可收缩、新建按钮不收缩。
- 多文件夹渲染时，筛选、删除和新建按钮均存在。
- 相关单元测试、TypeScript 检查和 H5 构建通过。
