# 社区发布、标签筛选与作品文件夹：任务需求文档

## 目标

让创作者能够有序管理自己的拼豆作品，并让社区作品具备稳定、可搜索、可筛选的分类信息。

本任务覆盖三项连续流程：

1. 保存作品时选择归属文件夹。
2. 我的作品页新建文件夹、查看文件夹内容、移动作品。
3. 分享作品到社区时确认发布并选择必选标签；发现页支持关键词搜索和标签筛选。

## 非目标

- 本期不开放任意自由文本标签。
- 本期不做文件夹分享、协作、嵌套文件夹或回收站。
- 本期不做评论标签、用户标签、作品收藏夹。
- 本期不做基于标签的推荐算法。

## 用户故事

### 创作者保存和整理作品

- 作为创作者，我可以在保存作品时选择一个已有文件夹，或直接保存到“未分类”。
- 作为创作者，我可以在“我的作品”中新建文件夹。
- 作为创作者，我可以把已有作品移动到一个文件夹，或移回“未分类”。
- 作为创作者，我可以按文件夹查看作品，不必在全部作品中反复查找。

### 创作者发布社区作品

- 作为创作者，我点击“分享到社区”后，必须先确认发布意图，而不会立即公开。
- 作为创作者，我必须从预设标签中选择 1–3 个标签，才能确认发布。
- 作为创作者，我可以取消发布确认，作品保留在我的作品中且不公开。
- 作为已发布作品的作者，我可以补充或修改社区标签。

### 浏览社区作品的用户

- 作为浏览者，我可以按作品名、作者名或标签搜索社区作品。
- 作为浏览者，我可以选择一个或多个标签筛选作品。
- 作为浏览者，我可以在“最新”和“热门”排序下继续保留搜索和标签筛选条件。
- 作为浏览者，我可以从作品卡片和详情页直接看到作品标签。

## 业务规则

### 文件夹

- 每个文件夹只属于一个用户，用户之间不可见。
- 默认存在逻辑分类“未分类”，不需要创建数据库文件夹记录。
- 文件夹名称：1–30 个字符；同一用户下名称唯一；去除首尾空格。
- 文件夹仅支持一级，不支持子文件夹。
- 一个作品最多属于一个文件夹，也可以不属于任何文件夹。
- 删除文件夹前必须确认；删除后，文件夹内作品移动到“未分类”，作品本身不删除。
- 移动作品不会改变作品内容、分享状态、评论、点赞和拼豆会话。

### 社区标签

- 标签为发布社区作品的必填项，至少 1 个、最多 3 个。
- 仅允许从受控预设标签中选择，不允许自由输入。
- 首批预设值：`动物`、`人物`、`植物`、`食物`、`风景`、`动漫`、`游戏`、`节日`、`文字`、`新手`、`其他`。
- 标签需去重；提交前清理空格；服务端必须二次校验。
- 已经发布但无标签的历史作品：仍在“全部”和关键词搜索结果中出现；当用户按具体标签筛选时不出现，直到作者补标签。
- 已发布作品允许作者编辑标签；编辑后社区搜索与筛选结果应立即更新。

### 分享确认

- 从“我的作品”点击“分享到社区”时，打开“发布到社区”确认弹窗。
- 保存作品时若选择“分享到社区”，作品先保存成功，再打开同一发布确认弹窗。
- 确认弹窗必须展示：作品缩略图、名称、网格尺寸、公开提示、标签选择器。
- 未选择标签时，“确认发布”按钮禁用，并显示“请至少选择一个标签”。
- 点击“取消”不改变作品分享状态。
- 点击“确认发布”后才调用分享接口；接口成功后将作品标记为已分享到社区。
- 已分享作品再次进入发布相关操作时，显示“编辑社区标签”，不能重复发布。

### 搜索与筛选

- 搜索关键词匹配：作品名称、作者名称、标签名称。
- 输入搜索词使用 250–300ms 防抖；切换排序或标签时立即查询。
- 标签支持多选；多个标签默认采用“命中任意标签（OR）”规则，避免结果过少。
- “全部”清除全部已选标签。
- 排序在搜索和标签筛选结果内生效：
  - 最新：按分享发布时间倒序。
  - 热门：按点赞数倒序；同分时按分享发布时间倒序。
- 无结果时显示空状态，并提供“清空筛选”。

## 页面与交互设计

### 我的作品

页面新增文件夹区域，推荐置于作品统计下方、作品网格上方：

```text
我的创作

[全部作品 12] [未分类 3] [动物作品 4] [节日礼物 5] [+ 新建文件夹]

当前文件夹：全部作品                         [管理]
作品网格
```

- 点击文件夹：筛选当前作品网格。
- 点击“新建文件夹”：输入名称后创建。
- 点击“管理”：进入文件夹管理模式，可重命名、删除文件夹。
- 作品操作菜单新增“移动到文件夹”。
- 已分享作品的操作菜单新增“编辑社区标签”。

### 保存作品

保存弹窗新增“保存位置”选择项：

```text
保存位置
[未分类 ▼]
```

- 默认选择上次使用的文件夹；若该文件夹已删除，则回退到“未分类”。
- 可在下拉项底部快捷“新建文件夹”。

### 发布到社区确认弹窗

```text
发布到社区
作品缩略图 / 名称 / 尺寸

发布后，所有用户都可以浏览、点赞和评论。

选择标签（1–3 个）
[动物] [人物] [植物] [食物] [风景]
[动漫] [游戏] [节日] [文字] [新手] [其他]

[取消] [确认发布]
```

- 已选标签具有明显选中态和勾选标识。
- 达到 3 个后，其他标签不可再选，并提示“最多选择 3 个标签”。

### 发现页

```text
[搜索图纸、作者、标签                         ×]

全部  动物  人物  植物  食物  风景  动漫  游戏 …

最新 | 热门

作品卡片：
标题
#动物  #动漫
作者头像 作者名                 爱心 12  评论 3
```

- 标签条横向滚动，不换行挤压卡片。
- 卡片显示最多 2 个标签；超过时显示 `+N`。
- 详情页展示完整标签；点击标签可返回发现页并带入该标签筛选。

## 数据模型

### 文件夹

```sql
CREATE TABLE project_folders (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  name TEXT NOT NULL,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  UNIQUE(user_id, name)
);

ALTER TABLE projects ADD COLUMN folder_id TEXT;
CREATE INDEX idx_projects_user_folder_updated
  ON projects(user_id, folder_id, updated_at DESC);
```

### 标签

```sql
CREATE TABLE project_tags (
  project_id TEXT NOT NULL,
  tag TEXT NOT NULL,
  created_at TEXT NOT NULL,
  PRIMARY KEY(project_id, tag)
);

CREATE INDEX idx_project_tags_tag_project
  ON project_tags(tag, project_id);
```

标签通过关联表保存，避免 JSON 字段难以索引、难以筛选和难以维护的问题。

## 接口设计

### 文件夹接口

```text
GET    /api/project-folders
POST   /api/project-folders                 { name }
PATCH  /api/project-folders/:folderId       { name }
DELETE /api/project-folders/:folderId

PATCH  /api/projects/:projectId/folder      { folderId: string | null }
```

项目保存/更新接口增加可选字段：

```text
folderId: string | null
```

### 社区标签与发布接口

```text
POST  /api/projects/:projectId/share
body: { tags: string[] }

PATCH /api/projects/:projectId/community-tags
body: { tags: string[] }

GET   /api/community/tags
GET   /api/community/posts?sort=hot|latest&q=关键词&tags=动物,动漫&page=1&pageSize=20
```

社区作品返回值增加：

```ts
tags: string[]
```

## 前端状态与组件边界

- `ProjectFolder`：文件夹数据类型与请求函数。
- `CommunityTag`：受控预设标签常量和校验函数。
- `FolderPicker`：保存页和移动作品操作共用。
- `ProjectFolderDialog`：新建、重命名、删除文件夹。
- `ShareCommunityDialog`：发布确认和编辑标签共用。
- `CommunityTagSelector`：最多三选、必选校验。
- `CommunityFilterBar`：搜索框、标签筛选、排序状态。
- `CommunityPatternCard`：展示标签，首页热门卡片和发现页复用。

## 接口安全与一致性

- 所有文件夹接口验证文件夹属于当前用户。
- 保存/移动作品时验证作品属于当前用户，且目标文件夹也属于当前用户。
- 分享、编辑标签仅允许作品作者调用。
- 标签校验必须在服务端执行，不能仅依赖前端禁用按钮。
- 删除文件夹和发布作品均需确认；删除文件夹不得删除作品。
- 多表写入（发布状态与标签替换、文件夹删除与作品归档）使用事务。

## 验收标准

### 文件夹

- 可新建、重命名、删除文件夹。
- 删除文件夹后，其中作品仍存在并显示在“未分类”。
- 保存作品可选择文件夹；移动作品后立即出现在目标文件夹。
- 从“全部作品”和特定文件夹之间切换时，作品数和列表正确。

### 分享与标签

- 点击分享先出现确认弹窗，不会立即公开。
- 未选标签时不能确认发布。
- 选择 1–3 个预设标签后才能发布。
- 取消确认不会改变分享状态。
- 已分享作品可修改标签；标签修改后卡片和详情同步更新。

### 搜索与筛选

- 可用作品名、作者名、标签搜索。
- 单标签、多标签、“全部”、最新/热门组合结果正确。
- 搜索、筛选和分页由服务端处理。
- 无结果有明确空状态和清空筛选动作。
- 首页热门卡片、发现页列表、详情页的标签数据一致。

## 实施顺序

1. 数据库迁移：文件夹、项目归属字段、项目标签表与索引。
2. 后端：文件夹 CRUD、作品归属移动、标签校验、分享与社区查询扩展。
3. 前端：数据类型、请求层和状态管理。
4. 我的作品：文件夹列表、创建/管理、保存选择、移动作品。
5. 发布确认：标签选择器、发布确认、编辑社区标签。
6. 发现页：搜索防抖、标签条、服务端筛选、标签展示、空状态。
7. 测试：权限、事务、历史作品兼容、搜索筛选组合、发布取消与标签必填。

## 决策记录

- 标签采用预设值，且发布时必选 1–3 个。
- 预设集中保留“其他”，不开放自由输入。
- 多标签筛选使用 OR 逻辑。
- 文件夹仅一级，删除时作品归入未分类。
- 历史已分享作品不强制迁移标签，保证现有社区内容可继续访问。
