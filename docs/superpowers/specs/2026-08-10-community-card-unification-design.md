# 社区热门卡片统一设计

## 目标

首页“热门模板”和发现页社区列表使用同一个社区作品卡片组件，避免图片、作者、点赞、评论等字段在两个页面重复维护。

## 方案

新增 `CommunityPatternCard`，负责渲染一个社区作品卡片的共同内容：作品图片/空状态、标题、作者头像与名称、点赞数和评论数。组件接收 `PatternListCard`、打开作品回调和可选的打开作者回调，并允许传入外层布局所需的 className。

首页继续使用横向预览布局，发现页继续使用瀑布流布局；两者的差异只保留在外层容器和 CSS 类名，不再复制卡片内部 JSX。

## 数据与交互

两页继续使用现有 `communityCards` 数据和已有的作品/作者点击回调。热门列表仍由 `communityPosts` 的热门请求产生，首页只取前三条。此次不改变 API、排序、分页或详情页行为。

## 验证

为共享卡片增加渲染测试，覆盖图片、标题、作者、点赞和评论字段；运行相关 Vitest 测试和 H5 构建，确认现有首页/发现页行为不回归。
