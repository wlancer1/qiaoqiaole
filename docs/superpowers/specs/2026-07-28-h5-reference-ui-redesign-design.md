# H5 首页、分割设置与浏览图 UI 重设计

## 背景

当前 H5 已具备图片上传、快速分割、对格子、浏览参数、去杂色合并、豆子清单和导入画布等完整功能，但首页、分割设置和浏览图的视觉语言不统一，移动端信息层级也不够清晰。

本次重设计以项目根目录的 `image copy.png` 为视觉参考，采用用户确认的“A：参考图高保真精简版”。目标是高度接近参考图的深蓝品牌区、亮蓝主操作、白色工具卡片和紧凑移动端布局，同时只展示项目中真实存在的功能和数据。

## 目标

- 统一首页、分割设置和浏览图的颜色、圆角、间距、阴影与交互反馈。
- 让上传图片成为首页最突出的主操作。
- 让图片预览成为分割设置和浏览图的视觉中心。
- 提升参数调节和豆子清单在手机上的可读性与可操作性。
- 保留现有 Canvas、网格、图片移动缩放、颜色统计、去杂色合并和导入逻辑。
- 所有主要触控目标保持至少 44 × 44px。

## 非目标

- 不新增“最近项目”“热门图纸”等没有真实数据来源的模块。
- 不改变分割、对格子、颜色采样或导入画布的业务逻辑。
- 不在本次实现均值匹配和 K-means 算法。
- 不重构画布编辑器、仓库或登录流程。
- 不新增外部 UI 依赖或图标库。

## 统一设计系统

### 颜色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 品牌深色 | `#071C48` | 首页品牌区、深色文字强调 |
| 品牌主色 | `#146CFF` | 主按钮、选中态、滑块进度 |
| 页面背景 | `#F4F7FC` | 三页工作区背景 |
| 内容表面 | `#FFFFFF` | 工具卡片、参数卡片、清单项 |
| 主文字 | `#101828` | 标题、关键数字 |
| 次文字 | `#718096` | 说明文字、辅助标签 |
| 边框 | `#E6EDF7` | 卡片边界、分隔线 |

颜色应通过页面级 CSS 自定义属性提供，避免在组件内部散落新的无体系色值。

### 字体

- 沿用项目当前中文字体栈，不引入网络字体。
- 页面主标题使用 800–900 字重。
- 卡片标题和关键按钮使用 700–800 字重。
- 正文使用 500–650 字重。
- 网格尺寸和豆子数量启用等宽数字特性。

### 间距与尺寸

- 基础间距序列：4、8、12、16、24px。
- 手机内容区水平边距：16px。
- 小控件圆角：12px。
- 功能卡片圆角：16px。
- 主操作卡片圆角：22px。
- 主要按钮和可点击控件最小尺寸：44 × 44px。

### 阴影与动效

- 普通卡片使用轻量蓝灰阴影和细边框。
- 亮蓝主操作使用中等蓝色阴影。
- 不使用大面积渐变光晕或多层重阴影。
- 按下反馈、页签切换和卡片状态变化使用 160–220ms ease-out。
- `prefers-reduced-motion: reduce` 时关闭非必要动效。

### 图标

- 继续使用项目现有 `Icon` 组件和现有线性 SVG。
- 不使用 emoji 代替图标。
- 不引入新的图标依赖。

## 首页设计

### 页面结构

1. 深海军蓝品牌区。
2. 亮蓝色上传图片主操作卡片。
3. “创作工具”真实功能区。
4. 有真实颜色数据时显示的已用颜色条。
5. 固定底部导航。

### 品牌区

- 显示“超级拼”和简短副标题“让拼豆创作更简单”。
- 移除当前没有实际处理行为的消息入口，避免展示不可用功能。
- 品牌区与页面背景形成清晰上下分区。

### 上传主操作

- 使用整行亮蓝卡片，文案为“上传图片制作拼豆图纸”。
- 辅助文案显示支持的 PNG、JPG 和 WebP。
- 右侧固定使用白色圆形箭头作为进入提示；整张卡片是唯一点击目标，箭头仅作装饰并设置 `aria-hidden`，不嵌套第二个按钮。
- 点击继续调用现有上传弹窗，不改变上传流程。

### 创作工具

三列展示现有真实入口：

- 拼豆图纸：上传图片生成。
- 敲豆图纸：上传图片后导出 STL。
- 空白画布：设置尺寸后自由绘制。

工具卡片使用白色表面、蓝色图标容器和轻边框。内容区不展示没有数据来源的项目或模板。

### 底部导航

- 保留首页、中央上传和我的。
- 中央上传使用亮蓝圆形悬浮按钮。
- 导航背景使用半透明白色和顶部细分隔线。

## 分割设置设计

### 顶部栏

- 标题改为“分割设置”。
- 左侧保留返回。
- 右侧“下一步”使用蓝色强调，并保持 44px 高度。

### 模式选择

- “快速分割 / 对格子”置于预览图上方。
- 使用浅蓝灰分段容器，当前模式为亮蓝填充。
- 切换只改变现有 `splitMode`，不改变逻辑。

### 预览区

- 图片和网格继续由当前 Canvas 绘制。
- 预览区占据页面主要空间。
- 保留快速分割下的画布缩放，以及对格子模式下的图片平移、缩放和固定 3 × 3 控制区域。
- 网格、移动按钮、缩放按钮和蓝色拖动区域的定位逻辑不变。

### 快速分割参数

- 参数区显示“长边格数”和醒目的当前数值。
- 减号、滑块、加号在同一行。
- 下方显示预计列数、行数和总格数。
- 继续使用现有 `splitLongSide`、`activeSplitCols` 和 `activeSplitRows`。

### 对格子参数

- 将偏移、格距和重置整理为两组紧凑工具区。
- 方向微调按钮保持清晰的触控区域。
- 格距增减和重置按钮保持现有行为。
- 对格子的实时读数继续显示，但降低为辅助信息。

## 浏览图设计

### 顶部栏与图纸信息

- 顶部仅保留返回、标题“浏览”和“导入画布”。
- 图纸名称和 `列 × 行` 放在预览图上方。
- 删除重复的英文 eyebrow 和过长说明，减少首屏占用。

### 图纸预览

- 预览图位于页面视觉中心。
- 保持 `activeSplitCols / activeSplitRows` 的真实宽高比。
- 使用轻边框和轻阴影，不添加不属于图纸的装饰。

### 页签

- “参数设置 / 豆子清单”使用浅蓝灰分段容器。
- 当前页签使用亮蓝填充和白色文字。
- 豆子清单页签显示真实颜色种类数量。

### 参数设置

- 显示当前实际生效的“众数投票”说明，不提供可误导的可用算法切换。
- 去杂色合并使用真实的用量阈值语义。
- 控件包含当前值、减号、滑块、加号和准确说明。
- 文案明确为“使用数量 ≤ N 颗的颜色替换为最接近的常用颜色”。
- 阈值范围保持 0–20。

### 豆子清单

- 顶部显示真实颜色种类和总豆子数。
- 每行显示色号、色块、HEX 和数量。
- 按数量从高到低排序。
- 阈值变化后清单与预览同步更新。

## 响应式行为

### 手机（≤ 480px）

- 页面内容使用 16px 水平边距。
- 首页三列工具保持三列，但压缩说明字号，避免溢出。
- 分割参数使用固定底部面板；面板自身在内容超高时纵向滚动，预览区通过 `--split-controls-space` 预留面板高度，不产生页面级双滚动。
- 快速分割面板目标高度不超过 190px；对格子面板目标高度不超过 260px，并包含底部安全区。
- 浏览页图纸信息采用单行紧凑布局。
- 参数说明允许换行，滑块保持可用宽度。
- 豆子清单采用单列列表。

### 平板与桌面（> 480px）

- 首页、分割参数和浏览内容最大宽度统一为 720px，并水平居中。
- 以 1280 × 800 为桌面验收视口；分割预览可用高度不得低于 360px。
- 不将手机卡片无限拉宽。
- 分割和浏览预览允许更大的展示区域。

## 状态与反馈

- 按钮提供默认、按下、聚焦和禁用状态。
- 页签使用 `aria-selected` 表达当前状态。
- 滑块保留可访问名称和键盘操作。
- 上传、登录和导入的现有状态提示不改变。
- 空豆子清单不伪造数据；显示真实的 0 种颜色和 0 颗豆子。
- “下一步”仅在 `uploadedSplitImage` 存在时可用；当前分割页面的渲染条件已保证该状态，因此不新增异步加载态。
- “导入画布”在 `splitPreviewCells.length === 0` 时禁用，使用现有禁用视觉，不触发导入函数；有格子时立即可用。

## 数据流

- 首页入口继续调用现有 `openUpload`、`openCreateCanvasModal` 等处理函数。
- 分割设置继续使用现有图片、裁剪、网格和对齐状态。
- 浏览参数继续从 `rawSplitPreviewCells` 生成 `splitPreviewCells`。
- `splitMergeThreshold` 同时驱动浏览预览、豆子清单和最终导入。
- `importSplitToCanvas` 继续写入合并后的单元格，不新增第二套处理路径。
- 当所有颜色用量都小于等于阈值、没有用量更高的候选颜色时，颜色合并算法保留全部原色；参数说明补充“若没有常用颜色，则保留原色”。

## 组件边界

业务状态和处理函数继续由 `H5App` 持有，视觉重构不搬迁图片数据、网格手势或历史状态。新增或整理的展示单元只通过 props 接收状态和回调，不在组件内部复制业务状态：

- `HomeUploadHero`：接收 `onUpload`；只负责品牌主操作卡片，不处理文件读取。
- `FlowTopbar`：接收 `title`、`backLabel`、`onBack` 和可选右侧操作；供分割设置和浏览图复用。
- `SegmentedControl<T>`：接收选项、当前值和 `onChange`；供分割模式与浏览页签复用，使用 `tablist` / `tab` 和 `aria-selected`。
- `ThresholdControl`：接收 `value`、`min`、`max` 和 `onChange`；只负责减号、滑块、加号和说明，不执行颜色合并。
- `SplitBeadList`：接收排序后的颜色条目和总豆子数；只负责真实清单与空态展示。
- 图片 Canvas、`SplitPreviewCanvas`、`GridAlignmentHandles` 和豆子清单数据计算保持现有边界与调用方式。

这些展示单元统一放在 `apps/h5/src/H5FlowComponents.tsx`，该文件只包含无业务状态的流程展示组件，总长度目标不超过 260 行，单个组件不超过约 100 行。`H5App.tsx` 继续持有业务状态与回调。共享设计令牌仅定义在 `.h5-home-shell` 和 `.split-page` 的 CSS 自定义属性中，由三个页面消费。

```text
   │  ├─ brand-hero

   ├─ FlowTopbar（固定顶部）

      ├─ split-grid-preview
      ├─ SegmentedControl
      └─ settings-panel | bead-list-panel
```
