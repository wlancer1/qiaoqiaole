# 记住手机号和密码设计

## 目标

在现有 H5 手机号登录弹窗中增加“记住手机号和密码”功能。用户勾选后，当前浏览器下次打开登录弹窗时自动填充手机号和密码；未勾选时不保留已保存的登录凭据。

## 方案

新增独立的本地存储记录，不复用 `qiaoqiaole.auth` 会话记录。会话记录继续只保存 token 和身份提示，记忆登录记录使用独立 key 保存手机号、密码和启用标志。

凭据存储 helper 负责：

- 读取并校验手机号、密码和标志；
- 写入勾选后的登录凭据；
- 未勾选登录成功时清除记录；
- 处理损坏 JSON、字段类型错误和浏览器存储不可用等情况而不阻断登录。

登录弹窗仅在手机号登录模式显示复选框。弹窗打开时读取已保存记录并填充表单；切换注册模式时隐藏复选框，注册成功不保存密码。退出登录不主动清除已记忆凭据，用户取消勾选并再次登录成功时清除。

## 安全边界

密码会以浏览器本地可读形式保存在 `localStorage`，这是自动填充密码所需的取舍。凭据不发送到后端以外的接口，不写入会话 token 记录，不影响服务端认证协议。

## 测试

- helper 可读写和清除合法记录；
- 损坏记录、错误字段类型和存储异常不会抛错；
- 登录模式能展示并恢复复选框、手机号和密码；
- 勾选登录成功后保存凭据；
- 未勾选登录成功后清除凭据；
- 注册模式不保存密码。
