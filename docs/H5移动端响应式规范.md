# H5 移动端响应式规范

## 适配目标

H5 以手机浏览器为优先，但不绑定任何单一机型。主要覆盖 320–430 CSS 像素宽度的竖屏手机，并保证横屏、浏览器动态地址栏与安全区不会遮挡交互。

## 尺寸策略

- `rem` 用于颜色、间距、圆角、字号、控件高度等设计 token，保持页面视觉节奏一致。
- 根字号使用稳定、可随浏览器文字设置缩放的设计 token 基准，不能按某个设备宽度等比缩放；窄屏和宽屏的变化由流式容器、`clamp()` 与布局规则处理，避免触摸目标被缩小。
- 宽度优先使用 `min()`、`max()`、`clamp()`、百分比、Flexbox 与 Grid；内容列使用最大宽度，而不是固定手机宽度。
- 高度优先使用 `dvh`，并结合 `env(safe-area-inset-top)` / `env(safe-area-inset-bottom)`。
- 断点只在内容开始拥挤或布局需要改变时设定，不以 iPhone 型号命名。

## 保留像素单位的例外

- `1px` 边框和发丝线；
- Canvas 2D 的 `context.font` 与像素级绘制；
- 需要保持为物理像素的图像采样、导出和网格计算。

## 交互约束

- 可点按的主要控件在任何目标手机宽度上均不小于 44 CSS 像素；
- 文本不依赖纯 `vw` 缩放，以保留浏览器文字缩放能力；
- 不出现页面级横向滚动；可滚动内容由局部容器负责；
- 画布/预览比例保持真实列数与行数，控制器不得遮挡核心画布内容。

## 验收视口

至少验证：320×568、360×800、393×852、414×896、430×932，以及一组低高度横屏视口。该覆盖已由 H5 E2E 回归测试执行。
