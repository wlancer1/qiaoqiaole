# H5 移动端响应式规范

## 适配目标

H5 以手机浏览器为优先，但不绑定任何单一机型。主要覆盖 320–430 CSS 像素宽度的竖屏手机，并保证横屏、浏览器动态地址栏与安全区不会遮挡交互。

## 尺寸策略

- `rem` 用于颜色、间距、圆角、字号、控件高度等设计 token，保持页面视觉节奏一致。
- 根字号使用稳定、可随浏览器文字设置缩放的设计 token 基准，不能按某个设备宽度等比缩放；窄屏和宽屏的变化由流式容器、`clamp()` 与布局规则处理，避免触摸目标被缩小。
- 宽度优先使用 `min()`、`max()`、`clamp()`、百分比、Flexbox 与 Grid；内容列使用最大宽度，而不是固定手机宽度。
- 高度优先使用 `dvh`，并结合 `env(safe-area-inset-top)` / `env(safe-area-inset-bottom)`。
- 断点只在内容开始拥挤或布局需要改变时设定，不以 iPhone 型号命名。

## 项目统一页面尺寸规则

新增或改造 H5 页面时，优先复用 `apps/h5/src/styles.css` 中已有的页面 token，不要为单个页面重新放大一套 `rem` 尺寸。

- 内容列使用 `--flow-content-max`，页面两侧内边距优先使用 `0.4444rem–0.508rem`；卡片、搜索框、筛选区和网格应共用同一条内容边界。
- 顶部导航沿用 `--split-topbar-height`，当前基准为 `calc(1.841rem + env(safe-area-inset-top))`；标题、返回按钮和右侧信息保持与拆分流程页面同一视觉高度。
- 常规页面区块间距以 `0.254rem–0.508rem` 为主，避免使用 `0.8rem` 以上的大间距；普通卡片最小高度和字号应参考现有首页、消息页、拆分页，而不是按截图像素直接放大。
- 搜索框高度基准约为 `1.2698rem`，字母/标签按钮高度基准约为 `0.9524rem`；主要可点按控件仍须满足至少 44 CSS 像素的触摸目标。
- 四列色卡、列表和统计卡使用流式 Grid/Flex 排布，不能写死手机像素宽度；底部操作栏的内容区域与上方卡片保持相同左右边界。
- 固定底部操作栏必须使用 `env(safe-area-inset-bottom)`，并为滚动内容预留对应底部空间，不能遮挡最后一行内容。
- 页面状态按数据分层展示：没有仓库时只显示创建仓库引导，不显示色卡、筛选和出入库操作；创建数据容器后再显示对应管理控件。
- 页面图标统一使用项目已接入的 Lucide 图标库，不使用手绘 SVG 或文字字符模拟操作图标。

## 保留像素单位的例外

- `1px` 边框和发丝线；
- Canvas 2D 的 `context.font` 与像素级绘制；
- 需要保持为物理像素的图像采样、导出和网格计算。

## 交互约束

- 可点按的主要控件在任何目标手机宽度上均不小于 44 CSS 像素；
- 文本不依赖纯 `vw` 缩放，以保留浏览器文字缩放能力；
- 不出现页面级横向滚动；可滚动内容由局部容器负责；
- 画布/预览比例保持真实列数与行数，控制器不得遮挡核心画布内容。

## 验收视口

至少验证：320×568、360×800、393×852、414×896、430×932，以及一组低高度横屏视口。该覆盖已由 H5 E2E 回归测试执行。
