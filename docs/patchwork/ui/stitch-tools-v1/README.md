# 拼布画笔与缝纫线 · 方案与交互设计稿

版本：V1 方案稿 · 2026-10-21。对应现有 H5 拼布编辑器。当前交付为方案和可点击设计稿，尚未实现生产功能。

打开同目录 [index.html](./index.html) 可查看四屏设计稿。无外部依赖，离线可用。可切换模式、针迹、颜色、粗细、距边缘，查看即时预览，并取消或应用。截图与渲染脚本见同目录。

## 1. 建议的交互

保留左侧一个「画笔」入口。点击进入设置；激活后在画布上方保留当前模式小标签，点标签可再次调整。画笔设置分为「形状」和「缝纫线」，保留用户上一次选择，不增加独立的左侧工具。

| 操作 | 产生的内容 | 操作结束 | 后续编辑 |
| --- | --- | --- | --- |
| 形状 → 自由绘制 | 一块闭合布片，使用当前布料 | 松手闭合轮廓 | 沿用现有节点、属性、填布操作 |
| 形状 → 矩形 / 椭圆 / 更多形状 | 一块基础形状布片 | 拖动确定大小与位置 | 可在属性精确修改尺寸 |
| 缝纫线 | 一条独立的针迹路径 | 松手结束这一条，不自动闭合；可继续画下一条 | 选择、移动、旋转、删除、锁定、改线色 |
| 选中布片 → 属性 → 缝纫线 | 围绕布片的一圈针迹 | 预览后点「应用到布片」 | 修改布片轮廓时重新生成，始终跟随布片 |

「更多形状」复用现有形状库，保持每行 4 个和上拉加载。卡片只显示形状与名称，不显示默认 10 × 10 cm。矩形/椭圆以拖动外接框为准，正方形/圆形等固定比例形状保持比例。自由绘制沿用当前手绘闭合逻辑。

绘制过程中，单指绘制，双指移动/缩放画布；取消手势不落笔。一次松手形成一次撤销记录，不将每个针脚保存为独立操作。绘制时保持连续笔画预览，结束后平滑与重采样。

## 2. 缝纫线设置

手绘缝线与布片周边缝线使用一个共享的设置面板；只根据目标显示不同选项。

| 项目 | 默认建议 | 规则 |
| --- | --- | --- |
| 针迹 | 平针 | 首版支持平针、回针、锁边针 |
| 线色 | 奶油白，记住上次设置 | 预设 5 色 + 自定义颜色；已应用的旧线不跟随全局设置变化 |
| 粗细 | 细 | 细 / 中 / 粗；建议渲染宽度 0.4 / 0.6 / 0.9 mm |
| 针长 | 3 mm | 放入「更多设置」；0.5–12 mm |
| 针距 | 2 mm | 放入「更多设置」；0.5–12 mm |
| 手绘路径 | 开放 | 松手结束，不自动将首尾连接 |
| 沿轮廓缝一圈 | 新布片默认关闭 | 在布片属性中启用；支持随时关闭且保留上次样式 |
| 距边缘 | 内侧 3 mm | 仅布片整圈缝线显示；0–12 mm，0.5 mm 步进 |

平针表现为间隔针脚；回针视觉上更连续；锁边针由沿边线与向布片内侧的短针脚组成，针脚方向随轮廓法线变化。针迹预览体现样式区别，不展开逐针操作教学。

设置采用临时草稿：调整时画布即时预览；「取消」、遮罩或正常 Esc 恢复原样式；「应用」一次性写入撤销栈。中文选字状态下的 Esc 不关闭面板。

## 3. 布片周边缝线

在现有「布片属性」中增加「缝纫线」一行，摘要显示针迹、线色和内侧距离；关闭时显示「未添加」。位置、旋转、尺寸、缝份等原有设置保留。无需再增加一个专门的画布工具。

点击这行进入「布片周边缝线」，显示所选布片名称。应用或取消后返回布片属性；直接从画布快捷入口进入时，完成后返回画布。

周边缝线是布片的附属样式，不是单独复制一圈可漂移的路径：

- 移动、旋转、镜像：与布片同步。
- 调整尺寸或编辑节点：按新轮廓重算；针长、针距、线粗和距边缘保持实际毫米值，不随布片被拉长。
- 换布料：保留缝线设置；用户可再选择更清楚的线色。
- 复制布片：连同缝线样式一起复制。
- 删除布片：一并删除附属缝线。
- 多选布片：可批量应用一个样式；每片按自己的轮廓生成，锁定布片跳过并明确反馈。
- 旧作品：没有缝线字段时按「未添加」显示。

**缝份和缝线独立。** 原有「缝份 mm」用于制作裁剪尺寸；「距边缘 mm」决定针迹离布片边缘的距离，二者不能复用同一个字段或互相覆盖。

## 4. 画布、图层与导出

独立手绘缝线是新的可选择对象，默认显示在布片上方，在图层中可单独命名、隐藏、锁定和删除。周边缝线不单独增加一行图层，随所属布片管理。

首版独立缝线路径之间可调整顺序；布片与缝线的交错穿插排序留作后续扩展，避免本轮重写全部图层模型。

屏幕上细线可设置最低可见像素，避免缩小时完全消失；其真实毫米参数不随显示缩放变化。默认成品 PNG 包含可见缝线。裁剪 PDF 保留原有裁剪线和缝份逻辑，新增可选的「缝线参考」层；默认不混入裁剪线，启用后用单独图例说明。

缝线不参与布片面积或现有布料库存扣减。保存或分享作品仅保存样式与路径，不产生任何新的库存消耗。

## 5. 实现建议

目前画笔在 PatchworkPage 中将一段 stroke 自动闭合成 Piece。建议增加 brushMode 与 shapePreset 状态；松手后根据模式分流到布片或独立缝线路径。沿布片周边的针迹可由形状实时推导，不保存每个针脚坐标。

建议的数据结构：

~~~ts
type StitchStyle = {
  kind: 'running' | 'backstitch' | 'blanket';
  color: string;
  widthMm: number;
  stitchLengthMm: number;
  gapMm: number;
};

type OutlineStitch = {
  enabled: boolean;
  insetMm: number; // 首版向内偏移
  style: StitchStyle;
};

type StitchPath = {
  id: string;
  name: string;
  points: Point[]; // 世界坐标，单位 mm
  style: StitchStyle;
  visible: boolean;
  locked: boolean;
};

// Piece.outlineStitch?: OutlineStitch
// PatchworkDocument.stitchPaths?: StitchPath[]
~~~

默认设置与已应用到作品中的样式应复制为独立对象，不共享可变引用。服务端与本地文档均需保留新字段；旧文档按默认值兼容，不重写已有布片。

建议抽出：
- BrushSettingsSheet：画笔模式与形状选择。
- StitchSettingsFields：两种场景共享针迹、线色、粗细、针长和针距。
- OutlineStitchSheet：布片目标信息、开关与内侧距离。
- stitchGeometry / stitchRenderer：按整条路径累计长度采样，保持跨线段针距连续，生成不同针迹。

内侧缝线应使用真正的多边形向内偏移，不能简单围绕中心等比缩小。对凹角、自交、多段偏移和极小布片做几何校验；偏移后没有可用闭合轮廓时提示「当前布片太小，请减小距边缘」，保留原有设置，不画错到边界外。

整圈针迹需要处理首尾接缝及尖角，锁边针需要稳定的内向法线。设计稿中的 SVG 为视觉示意，具体毫米与针脚排列以实现后的几何运算为准。

## 6. 交付与验收

设计稿四屏：
1. 画笔 / 形状：自由、矩形、椭圆、更多形状、当前布料。
2. 画笔 / 缝纫线：针迹、颜色、粗细、更多设置。
3. 布片属性：新增缝纫线入口，与已有布料和尺寸设置并列。
4. 周边缝线：启用、样式、颜色、粗细、内侧距离、预览应用。

实现验收重点：
- 两种画笔模式切换不丢草稿，形状不会错误变成线，开放线不会自动闭合。
- 形状库四列且不显示默认尺寸。
- 两种设置场景的针迹预览一致；自定义颜色、细线和深浅布料都可辨认。
- 周边缝线在缩放、旋转、改形、复制、撤销后仍贴合布片。
- 凹形、极小形状、偏移失败不破坏作品。
- 多选设置一次撤销可恢复全部原样式。
- PNG、裁剪 PDF 的针迹显示与选项一致；不改变布料面积和扣库。
- 复用应用级弹窗、滚动锁与中文组合输入保护；320–414 px 无横向溢出。
