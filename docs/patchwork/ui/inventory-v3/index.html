开发交付要点

1. 仓库职责独立：「布料仓库」与「豆子仓库」在「我的」页面并列为两个独立入口，进入布料仓库后不再混入「拼豆仓库」切换条。布料按花色品种 + 批次（整块布 / 余料 / 仅面积 / 仅记录拥有）管理，卡片同时展示代表规格、批次数与总可用面积。

2. 编辑器与选择器对齐真实代码：拼布编辑器顶栏采用左/中/右三栏（返回 + 作品尺寸胶囊、撤销/重做、用料/导出 + 保存胶囊），左栏为浮动工具卡，底栏为「布料」按钮 + 横向已用布料条。统一布料选择器（FabricPicker）采用 4 列圆角色卡 + 右下角选中勾号角标，供底部布料栏、底布设置、布片属性与缺料替换共用。

3. 用料计算与确认扣库闭环：用料清单明确展示「净面积 + 缝份 + 预计损耗 = 预计备料」及当前库存对比；缺料/不足同时提供「补充库存」与「替换布料」双路径。保存作品不扣库；确认实际裁剪时每种待扣布料均可独立选择批次并修改实际消耗量。

设计视口 390 × 844；同时适配 320 / 375 / 414 CSS px。按浏览器打印可导出逐页评审稿。
