# 布料仓库与库存管理 UI · V3
日期：2026-10-19
依据：本目录 `requirements-source.md` 与项目真实代码（`PatchworkPage.tsx`、`FabricPicker.tsx`、`HomeShellPage.tsx`、`AGENTS.md`）。

## 查看
直接打开 `index.html`。总览展示 13 张移动端稿和 1 张桌面稿；点击「单屏交互预览」可按页面跳转。PNG 在 `screenshots/`，`00-all-screens.png` 是总览。

## 导航归属与职责边界
- **布料仓库与豆子仓库完全独立**：在「00 我的」页面中，「豆子仓库」与「布料仓库（我的布料）」作为两个并列的独立入口卡片。进入「01 我的布料」后不再混入 `[拼豆仓库 | 布料仓库]` 切换栏，避免把 MARD 色号颗数体系与拼布花色/布块批次/面积体系耦合在一起。
- 路由层级：`我的 → 我的布料 → 布料详情 / 添加布料 / 库存流水`。个人中心和布料仓库统一使用 `--flow-*` Token，拼布画布编辑器使用 `--blue`。

00 我的入口；01 我的布料（独立仓库）；02 上传及批次录入；03 布料详情与分批库存；04 统一布料选择器；05 缺料画布；
06 项目用料清单；07 缺料替换范围；08 裁剪确认；09 库存扣减记录；10 空仓库；11 异常与边界保护；12 冲正流水与余料入库；13 桌面端仓库。

## 本次审查发现并修正的设计问题
1. **移除布料仓库内的「拼豆仓库」混入导航（01 / 10）**：
   - 原稿在「00 我的」已有独立入口的情况下，又在「01 我的布料」页面内顶部塞入 `拼豆仓库 / 布料仓库` 切换栏。现已彻底移除，改为布料专属的库存概览统计条（仓库布料数、可用总面积、偏低/用完提醒）和「库存流水」快捷入口。
2. **补齐布料规格、批次数与状态角标，统一前后数据（01 / 02 / 03）**：
   - 原稿列表卡片只显示 `8,000 cm²` 纯面积，看不出是整块布还是碎布，且 `02 上传`（100×80 cm）与 `03 详情`（80×75 cm 整布 + 2,000 cm² 余料）数据矛盾。
   - 现统一为：列表卡片同时展示 **规格/批次说明**（如 `80×75 cm 等 2 批 · 棉布`）+ **右上角状态标签**（`2 批`、`整布`、`偏低`、`待核实`、`已用完`）+ **可用面积**，与详情页批次数据严格一致。
3. **修复上传表单的伪控件与缺失字段（02）**：
   - 原稿「分类」只是不可交互的静态文字 `棉布 ⌄`，且缺少「主色识别与修改」。现已改为真实 `<select>` 材质分类下拉框 + 主色拾色器（`type="color"`）。
4. **拼布编辑器与统一布料选择器对齐项目真实 UI（04 / 05 / 07）**：
   - 编辑器（04/05/07）对齐 `PatchworkPage.tsx`：三段式顶栏（`返回` + `20 × 20 cm ⌄` 底布胶囊、`撤销/重做`、`用料` + `保存`）、左侧悬浮工具栏（`选择/画笔/添加/填布/图层/清空`）、横纵厘米标尺、底部「布料」按钮 + 已用布料横向滚动条，移除原稿多余的悬浮按钮与重复底栏。
   - 统一布料选择器（04）对齐 `FabricPicker.tsx`：展示当前填充目标说明，4 列圆角色卡 + 右下角蓝底白勾徽标（`.pw-check-badge`），自动隐藏已用完布料。
5. **用料清单补齐面积拆解公式与「补充库存 + 替换布料」双操作（06）**：
   - 明确展示 `净面积 + 缝份 + 预计损耗 = 预计备料` 以及当前仓库库存对比；对缺料/不足项同时提供 **「补充库存」** 与 **「替换布料」** 两个入口。
6. **裁剪确认页统一所有待扣减材料的批次与消耗量交互（08）**：
   - 原稿中第 2 项待扣材料「鼠尾草绿」被写死成静态文本，无法选批次或改实际消耗量。现已统一为每项待扣布料均可独立选择批次与修改实际消耗面积。
7. **修正空仓库二级页面误放一级底部 Tab 栏的问题（10）**，并补齐所有仅图标按钮的中文 `aria-label` 与遮罩点击关闭交互。
