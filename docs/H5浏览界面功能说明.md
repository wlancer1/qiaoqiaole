# H5 浏览界面功能说明

## 1. 功能概述

H5 图片分割流程用于将导入的图片转换成拼豆格子图，并在导入画布前提供浏览、颜色处理和豆子用量确认功能。

当前主要流程为：

```text
上传图片 → 分割设置 → 对格子 → 裁剪 → 浏览 → 参数设置 / 豆子清单 → 导入画布
```

支持 PNG、JPG、JPEG 和 WebP 图片，单张图片大小不能超过 20MB，图片最长边不能超过 4096 像素。

## 2. 分割设置界面

### 2.1 快速分割

快速分割会根据图片裁剪区域和长边格数，自动计算行数与列数。

用户可以通过以下方式调整格子数量：

- 点击减少格数按钮；
- 点击增加格数按钮；
- 拖动长边格数滑块；
- 查看当前生成的列数 × 行数。

快速分割预览会在画布中实时显示图片和分割线。

### 2.2 对格子

对格子用于将图片中的实际像素内容与拼豆网格进行对齐。

当前对格子区域固定为 3 × 3 格，用于辅助定位和缩放：

- 左上角为蓝色移动控制点；
- 右下角为橙色缩放控制点；
- 半透明蓝色区域可以直接拖动移动网格；
- 网格始终附着在图片上，不会与图片分离；
- 移动和缩放只影响网格与图片的对齐关系。

对格子页面支持：

- 在控制区域外拖动图片；
- 在控制区域外滚轮缩放图片；
- 点击控制区域外进行缩放；
- 双指操作进行触控缩放；
- 使用方向按钮微调网格位置；
- 使用格距按钮调整网格大小；
- 使用重置按钮恢复默认对格状态。

## 3. 裁剪步骤

分割完成后会先进入裁剪步骤。系统会根据分割结果中非透明格子的范围，自动生成初始裁剪框，默认去除图案外围的空白格子。

- 裁剪框始终吸附到格线；
- 四角拖拽可以调整要保留的格子范围；
- 裁剪框中实时显示“列数 × 行数”；
- 点击“重置”恢复自动识别的有效内容范围；
- 不提供固定比例切换，也不允许输入比例；
- 点击“确认裁剪”后，后续浏览和导入画布都使用裁剪后的格子矩阵。

## 4. 浏览界面

浏览界面用于在导入画布前确认最终格子效果。

### 3.1 页面结构

页面从上到下分为：

1. 顶部导航栏；
2. 图纸预览信息区；
3. 完整比例的格子预览图；
4. 参数设置 / 豆子清单页签；
5. 当前页签对应的内容区域。

顶部信息区显示：

- 页面标题“浏览”；
- 图纸尺寸，例如 `24 × 24`；
- 当前图纸的说明文字；
- “导入画布”按钮。

当前浏览页采用浅蓝灰工作区、白色内容卡片和蓝色状态强调，预览图作为页面的主要视觉内容。

### 3.2 图纸预览

预览图按照当前实际列数和行数生成，不再固定为正方形。

例如：

- 24 列 × 18 行会按照 `24 / 18` 的比例显示；
- 49 列 × 72 行会按照 `49 / 72` 的比例显示。

每个格子会显示最终处理后的颜色。透明格子使用浅灰色显示，避免与页面背景混淆。

## 5. 参数设置

参数设置页包含颜色匹配方式和去杂色合并两个部分。

### 4.1 颜色匹配方式

当前界面提供三个选项：

- 众数投票：推荐方式；
- 均值匹配：较快；
- K-means：适合颜色变化复杂的图片。

当前实际生效的是“众数投票”。均值匹配和 K-means 目前作为后续算法扩展的界面入口，点击后会提示暂未启用，不会改变当前生成算法。

### 4.2 去杂色合并

去杂色合并的阈值表示“颜色使用数量”，不是 RGB 颜色距离。

例如设置阈值为 5：

- 使用数量大于 5 颗的颜色作为常用颜色候选；
- 使用数量小于等于 5 颗的颜色视为低用量颜色；
- 低用量颜色会替换成常用颜色中 RGB 距离最近的颜色；
- 如果没有可用的常用颜色候选，则保留原颜色；
- 透明格子不会参与合并，也不会被替换。

阈值范围为 `0～20`：

- `0`：不合并；
- `1`：替换用量为 1 颗的颜色；
- `5`：替换用量为 1～5 颗的颜色；
- `20`：替换用量为 1～20 颗的颜色。

阈值可以通过以下方式修改：

- 拖动滑块；
- 点击左侧减号；
- 点击右侧加号。

浏览预览和点击“导入画布”使用同一套合并结果，确保预览效果与最终画布一致。

## 6. 豆子清单

豆子清单根据当前浏览预览中的最终格子颜色实时统计。

每一项包含：

- 色号，例如 `A7`；
- 颜色 HEX 值，例如 `#F4C7A1`；
- 当前颜色的使用数量；
- 颜色预览色块。

列表按照使用数量从高到低排序，方便优先准备使用量较多的颜色。

清单顶部显示：

- 当前使用的颜色种类数量；
- 当前总豆子数量。

调整合并阈值后，豆子清单会同步更新。

## 7. 导入画布

点击“导入画布”后：

1. 使用当前分割模式生成格子；
2. 应用当前去杂色合并阈值；
3. 将列数、行数和处理后的格子写入画布状态；
4. 进入画布编辑器；
5. 默认使用手抓移动工具；
6. 清空当前撤销和重做历史，开始新的编辑流程。

## 8. 画布编辑器

导入后进入完整画布工作区：

- 工作区域由全屏画布容器承载；
- 工具栏悬浮在画布上方；
- 背景使用浅色棋盘格，不使用纯黑背景；
- 支持画布整体平移；
- 支持滚轮缩放和按钮缩放；
- 支持 1:1 重置；
- 图片画布显示网格线和色号；
- 放大到一定比例后显示格子色号；
- 底部色卡用于选择绘制颜色。

## 9. 移动端适配

浏览页针对手机宽度进行了适配：

- 所有主要按钮保持至少 44px 触控尺寸；
- 预览图宽度随屏幕变化；
- 预览图保持实际列数与行数比例；
- 参数卡片不会超出屏幕；
- 阈值滑块两侧按钮不会被挤压；
- 匹配方式卡片在窄屏下保持三列紧凑布局；
- 豆子清单采用纵向列表；
- 说明文字会自动换行，不产生横向溢出。
